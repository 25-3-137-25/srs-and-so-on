# Документация REST API

Проект предоставляет REST API через Django REST Framework. Все эндпоинты, кроме публичных страниц, требуют аутентификации.

## Общие сведения

- **Базовый URL API:** `/api/`
- **Формат данных:** JSON
- **Аутентификация:** сессионная (через cookie)
- **CSRF-токен:** обязателен для изменяющих запросов (POST, PATCH, DELETE)
- **Кодировка:** UTF-8

---

## Приложение accounts

### POST /api/accounts/register/

Регистрация нового пользователя.

**Тело запроса:**

    {
      "username": "student1",
      "email": "student@example.com",
      "password": "secure_password_123"
    }

**Успешный ответ:** HTTP 201, JSON с данными созданного пользователя.

**Ошибки:**
- 400 — некорректные данные (слабый пароль, занятый username)

### POST /api/accounts/login/

Аутентификация пользователя.

**Тело запроса:**

    {
      "username": "student1",
      "password": "secure_password_123"
    }

**Успешный ответ:** HTTP 200, установка сессионной cookie.

**Ошибки:**
- 400 — неверные учётные данные

## Приложение groups

### GET /api/groups/

Получение списка учебных групп. Поддерживает фильтрацию.

**Параметры запроса:**
- `faculty` — фильтр по коду факультета
- `year` — фильтр по году набора

**Успешный ответ:** HTTP 200, JSON-массив объектов групп.

### POST /api/groups/

Создание новой учебной группы.

**Тело запроса:**

    {
      "name": "М3О-237БВ-25",
      "faculty": 1,
      "year": 2023
    }

**Успешный ответ:** HTTP 201, JSON созданной группы.

**Ошибки:**
- 400 — некорректные данные или дублирующее название
- 403 — недостаточно прав

### GET /api/groups/{id}/

Получение информации о конкретной группе.

**Успешный ответ:** HTTP 200, JSON объекта группы.

**Ошибки:**
- 404 — группа не найдена

### PATCH /api/groups/{id}/

Частичное обновление группы.

**Тело запроса:**

    {
      "year": 2024
    }

**Успешный ответ:** HTTP 200, JSON обновлённой группы.

**Ошибки:**
- 400 — некорректные данные
- 403 — недостаточно прав
- 404 — группа не найдена

### DELETE /api/groups/{id}/

Удаление учебной группы.

**Успешный ответ:** HTTP 204, пустое тело.

**Ошибки:**
- 403 — недостаточно прав
- 404 — группа не найдена

## Приложение inventory

### GET /api/inventory/equipment/

Получение списка оборудования (только чтение).

**Параметры запроса:**
- `category` — фильтр по категории (lab, pc, measure, tool)

**Успешный ответ:** HTTP 200, JSON-массив объектов оборудования.

### GET /api/inventory/equipment/{id}/

Получение информации о конкретной единице оборудования.

**Успешный ответ:** HTTP 200, JSON объекта оборудования.

**Ошибки:**
- 404 — оборудование не найдено

### GET /api/inventory/requests/

Получение списка заявок. Обычный пользователь видит только свои заявки, администратор — все.

**Параметры запроса:**
- `status` — фильтр по статусу (draft, approved, issued, returned, rejected)
- `category` — фильтр по категории оборудования

**Успешный ответ:** HTTP 200, JSON-массив заявок с вложенными событиями.

### POST /api/inventory/requests/

Создание заявки на оборудование. Составная транзакционная операция: создаёт заявку и резервирует количество на складе.

**Тело запроса:**

    {
      "equipment": 1,
      "quantity": 2,
      "purpose": "Для лабораторной работы"
    }

**Успешный ответ:** HTTP 201, JSON созданной заявки.

**Ошибки:**
- 400 — недостаточно оборудования на складе или некорректное количество
- 403 — не аутентифицирован

### GET /api/inventory/requests/{id}/

Получение информации о конкретной заявке.

**Успешный ответ:** HTTP 200, JSON заявки с историей событий.

**Ошибки:**
- 403 — заявка принадлежит другому пользователю
- 404 — заявка не найдена

### PATCH /api/inventory/requests/{id}/

Частичное обновление заявки (только для черновиков).

**Тело запроса:**

    {
      "quantity": 3,
      "purpose": "Новая цель"
    }

**Успешный ответ:** HTTP 200, JSON обновлённой заявки.

**Ошибки:**
- 400 — некорректные данные
- 403 — заявка не принадлежит пользователю или не в статусе draft
- 404 — заявка не найдена

### DELETE /api/inventory/requests/{id}/

Удаление заявки. Для черновиков возвращает зарезервированное количество на склад.

**Успешный ответ:** HTTP 204, пустое тело.

**Ошибки:**
- 403 — заявка не принадлежит пользователю
- 404 — заявка не найдена

### POST /api/inventory/requests/{id}/transition/

Изменение статуса заявки (бизнес-действие). Проверяет допустимость перехода согласно конечному автомату.

**Тело запроса:**

    {
      "new_status": "approved",
      "comment": "Согласовано преподавателем"
    }

**Успешный ответ:** HTTP 200, JSON обновлённой заявки.

**Ошибки:**
- 400 — недопустимый переход (например, из draft сразу в returned)
- 403 — заявка не принадлежит пользователю
- 404 — заявка не найдена
- 500 — ошибка транзакции

### GET /api/inventory/requests/{id}/history/

Получение истории событий конкретной заявки.

**Успешный ответ:** HTTP 200, JSON-массив событий с указанием инициатора, действия и времени.

**Ошибки:**
- 403 — заявка не принадлежит пользователю
- 404 — заявка не найдена

## Примеры использования API

### Создание заявки через fetch():

    const response = await fetch('/api/inventory/requests/', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-CSRFToken': getCookie('csrftoken')
      },
      body: JSON.stringify({
        equipment: 1,
        quantity: 2,
        purpose: 'Лабораторная работа'
      })
    });
    const data = await response.json();

### Смена статуса заявки:

    const response = await fetch('/api/inventory/requests/5/transition/', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-CSRFToken': getCookie('csrftoken')
      },
      body: JSON.stringify({
        new_status: 'approved',
        comment: 'Согласовано'
      })
    });

### Получение истории заявки:

    const response = await fetch('/api/inventory/requests/5/history/');
    const events = await response.json();

### Удаление заявки с подтверждением:

    if (confirm('Удалить заявку?')) {
      const response = await fetch('/api/inventory/requests/5/', {
        method: 'DELETE',
        headers: {
          'X-CSRFToken': getCookie('csrftoken')
        }
      });
    }
