# Система управления учебным порталом и заявками на оборудование

## Назначение

Веб-приложение для управления учебными группами и обработки заявок на выдачу лабораторного оборудования. Предназначено для использования преподавателями и студентами учебного заведения.

## Функциональность

- Регистрация и аутентификация пользователей
- CRUD-управление учебными группами с привязкой к факультетам
- Система заявок на выдачу оборудования с жизненным циклом (Создана → Согласована → Выдана → Возвращена)
- История событий по каждой заявке
- Разграничение доступа: пользователи видят только свои заявки
- Фильтрация заявок по статусу и категории оборудования

## Технологии

- **Backend:** Python 3.10+, Django 5.x, Django REST Framework
- **Frontend:** HTML5, JavaScript (fetch API), фреймворк Tabler
- **База данных:** SQLite (локально), PostgreSQL (production)
- **Сервер приложений:** Gunicorn (production)
- **Статические файлы:** WhiteNoise
- **Развёртывание:** Render (облачная платформа)
